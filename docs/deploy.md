# Как проект выкатывается

Актуально на 2026-11-09.

Программа работает на Mac оператора. Сервера и публикации нет.

## Где живёт

- Код — этот репозиторий. Оператор клонирует его или копирует папку.
- Данные — папка `workspace/` рядом с кодом (задаёт `dca.toml`) или любая папка с маркером `.dca.toml`. В git данных нет.

## Установка

1. Установите Python 3.11 или новее.
2. Установите зависимости:

   ```bash
   python3 -m pip install -r requirements-lock.txt
   ```

3. Проверьте установку:

   ```bash
   ./dca doctor
   ```

Установка пакета (`pip install -e .`) не нужна: `./dca` и runner'ы запускают код из `src/` рядом с собой.

Уточнение, актуально на 2026-11-09:

- Сохраните полную папку проекта, включая `templates/`, `data/` и `dca.toml`.
- Запускайте `./dca` из этой папки.
- Установленный wheel содержит код. Шаблоны и примеры Excel остаются в папке проекта.
- Для работы используйте полную копию проекта; отдельного wheel недостаточно.

## Обновление

1. Получите новую версию кода (`git pull`).
2. Запустите тесты: `python3 -m pytest`.
3. Обновите runner'ы в старых сделках: `./dca rewrite-runners --all`.
4. Добавьте новые поля в базу справочников: `./dca upgrade-db`.

## Проверка после обновления

- `./dca doctor` заканчивается строкой «✅ OK».
- Тестовая сделка из `data/input_example_FILLED.xlsx` собирается командой `./dca generate`.
